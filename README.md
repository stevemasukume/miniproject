# Campus Creative Lab

A complete ICS 2102 semester mini project: a five-page student club website built with HTML, CSS and JavaScript. It is compatible with GitHub Pages.

## Run locally

Because this version is static, open `index.html` directly in a browser or run any local static server.

## Pages

- `index.html` - home and club introduction
- `about.html` - mission, vision and committee
- `activities.html` - JavaScript-rendered event list
- `gallery.html` - responsive activity gallery
- `join.html` - JavaScript-validated join/contact form

## Deployment

1. Create a public GitHub repository.
2. Upload the contents of this folder.
3. Open **Settings > Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and the `/ (root)` folder, then click **Save**.
6. GitHub will provide a public URL after deployment.

The contact form validates and displays a confirmation message in the browser. GitHub Pages cannot store submissions on a server, so connect the form to a service such as Formspree if real messages need to be delivered.
